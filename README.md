## Descripción


Este proyecto consiste en analizar información de producción y tiempos de paro de máquinas para comprender mejor los procesos de una empresa y apoyar la toma de decisiones.


## Herramientas utilizadas


Python
SQL
Power BI
Grafana
## Desarrollo


1. Revisión de los datos.
2. Organización de la información.
3. Limpieza y transformación.
4. Preparación de los datos.
5. Creación de indicadores y gráficos.
6. Análisis de resultados.
7. Conclusiones y propuestas de mejora.


## Archivos entregados


Documento PDF con la explicación del proyecto.
Archivo ZIP con los códigos y recursos complementarios.
## Conclusión


Este proyecto nos permitió comprender cómo los datos pueden ayudar a identificar problemas en la producción y los tiempos de paro, facilitando el análisis y la toma de decisiones.
